CSV ▾

使い方

セクションと画像

  • セクションをクリックすると「貼り付け先」になり、その状態で Ctrl+V で画像を貼り付けられます
  • ドロップゾーンへのドラッグ&ドロップ、クリックしてのファイル選択でも画像を追加できます
  • 画像をクリックすると注釈エディタ（選択・四角・丸・矢印・ペン・テキスト・番号・モザイク・切り抜き）が開きます
  • 「差替」（または右クリック）で、キャプション・表示幅を残したまま画像だけ差し替え（注釈は引き継ぐか選択。右クリックからはクリップボードの画像でも差し替え可）
  • ⠿ をドラッグすると画像やセクションを並び替え・他セクションへ移動できます（画像はカードの左半分に落とすと前、右半分なら後ろへ）
  • 画像右端をドラッグ、または幅ボタンで表示幅を変更できます
  • キャプションの改行はエクスポート後も改行されます（<br> と書いても改行になります）

複数選択

  • 画像のチェックボックスで複数選択すると、画面下部のバーで幅の一括変更・別セクションへの一括移動・一括削除ができます
  • 選択中の画像のどれかの ⠿ をドラッグすると、選択した画像をまとめて（表示順のまま）移動できます

注釈エディタ

  • ← / → — 変更を自動保存して前後の画像へ移動
  • Ctrl+Z — 直前の書き込みを取り消し／Ctrl+Y — やり直し（全消去・切り抜きも戻せます）
  • 「選択」ツール — クリックで選択、ドラッグで移動、Delete で削除。選択中に色・線・文字サイズを押すとその図形に反映。テキストはダブルクリックで再編集
  • テキスト入力中 — Enter で改行、Ctrl+Enter または外側クリックで確定、Esc で取り消し
  • 「切り抜き」ツール — ドラッグで範囲を指定（やり直しは再ドラッグ）、画面下のバーか Enter で確定、Esc で解除。「保存」するまで元画像は変わりません
  • Esc — 未保存の変更を破棄して閉じる（図形を選択中は選択解除のみ）

キーボードショートカット

  • Ctrl+S — JSON保存
  • Ctrl+Z / Ctrl+Shift+Z（または Ctrl+Y） — 元に戻す/やり直す
  • Esc — 選択解除・メニューを閉じる

ファイル操作

  • 「JSON保存」「ファイル読込」— 作業データをファイルとして保存/読込（このツールが書き出したHTMLも読込可）。保存ファイル名には日時（秒まで）が付きます
  • 「プレビュー（印刷確認）」— 書き出し結果を別画面で確認
  • 「作業用HTML（原本入り）」— 単体で開けるHTMLファイルとして書き出し（再編集用に注釈前の原本も入ります。ファイル名に日時が付きます）
  • 「配布用HTML」— 注釈前の原本・図形を含まないHTML。モザイクで隠した内容が残らないため、社外へ渡すときはこちら
  • 右上の「CSV ▾」→「キャプション書出」— 全画像のキャプションを CSV（セクションNo・セクション名・画像No・キャプション）で保存。Excel で編集できます。= + - @ で始まるセルは Excel で数式にならないよう先頭に ' を付けて書き出し、読み込み時に外します
  • 「キャプション読込」— 編集した CSV を読み込み、セクションNo・画像No が一致する画像のキャプションを上書きします（Ctrl+Z で戻せます）

自動保存

  • 編集内容はブラウザに自動保存され、閉じてしまっても次回開いたときに復元を確認できます
画像ごとに幅（100% / 50% / 33% / 25%、またはカード右端をドラッグで自由調整）を選べます。横長のPC画面キャプチャは100%、縦長のプロパティ画面は33%前後、比較したい2枚は両方50%で自動的に横並びになります。Alt+PrintScreen → Ctrl+Vで直接貼り付け可能（貼り付け先はオレンジ枠のセクション）。サムネイルをクリックすると注釈エディタが開きます（選択・四角・丸・矢印・ペン・テキスト・番号・モザイク・切り抜き／←→で前後の画像へ移動）。「差替」でキャプションを残したまま画像だけ入れ替えられます。画像左上のチェックで複数選択→一括で幅変更・別セクションへ移動・削除（選択した画像の⠿をドラッグしてもまとめて移動）。キャプションは改行でき、右上のCSV ▾（キャプション書出／読込）でExcel編集もできます。Ctrl+SでJSON保存、Ctrl+Z / Ctrl+Yで元に戻す・やり直し。取り込む画像の縮小サイズ・保存形式は右上で選べます（このブラウザに記憶されます）。作業用HTMLは「ファイル読込」でそのまま読み戻せます（注釈前の原本も入るため、モザイクで隠した情報を社外に出さないときは配布用HTMLを使ってください）。

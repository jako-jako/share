◫証跡ギャラリー
←→キーでも移動（移動時に自動保存）
画像ごとに幅（100% / 50% / 33% / 25%、またはカード右端をドラッグで自由調整）を選べます。横長のPC画面キャプチャは100%、縦長のプロパティ画面は33%前後、比較したい2枚は両方50%で自動的に横並びになります。Alt+PrintScreen → Ctrl+Vで直接貼り付け可能（貼り付け先はオレンジ枠のセクション）。画像左上のチェックで複数選択→一括で幅変更・削除、⠿をドラッグで並び替え（他のセクションへ移動も可能。空のセクションへは点線の枠へドロップ）、サムネイルをクリックすると注釈エディタが開きます（四角で囲む・矢印・ペン・テキスト・モザイク／←→で前後の画像へ移動）。モザイクは元のピクセルを残さず塗り潰すので、社名・氏名・IPの伏せ字に使えます。右クリックで注釈編集・複製・削除メニュー。Ctrl+SでJSON保存、Ctrl+Z / Ctrl+Yで元に戻す・やり直しができます。取り込む画像の縮小サイズ・保存形式は右上で選べます（選択はこのブラウザに記憶されます。画面の文字を読ませたいならPNG、枚数が多くサイズを抑えたいならJPEG）。ツールバー右上に推定ファイルサイズを常時表示します。エクスポートしたHTMLは「ファイル読込」でそのまま読み戻せますので、配布したHTMLさえあれば再編集できます。エクスポート後のHTMLは画像をクリックで拡大（←→で送り、Escで閉じる）できます。

MD → HTML ダウンローダー

使い方

画面レイアウト

  • 入力欄とプレビューの間の境界線をドラッグすると、左右のペイン幅を変更できます
  • 境界線をダブルクリックすると幅が50:50にリセットされます
  • 境界線をクリックして選択した状態で ← / → キーでも微調整できます
  • 変更した幅はlocalStorageに保存され、次回開いたときも復元されます

ツールバー

  • H 見出し / B 太字 / I 斜体 / S 取り消し線
  • " 引用 / • 箇条書き / </> インラインコード / 🔗 リンク
  • 選択範囲があればそれを装飾、なければカーソル位置に記法を挿入します

キーボードショートカット

  • Tab / Shift+Tab — 選択行をインデント/解除
  • Ctrl+Z(MacはCmd+Z) — 元に戻す
  • Ctrl+Shift+Z — やり直す

画像

  • エディタへの貼り付け、またはドラッグ&ドロップで画像をBase64として本文に埋め込みます
  • 幅1600pxを超える画像は自動的に縮小されます

ファイル操作

  • 「Markdownインポート」— .md / .markdown ファイルを読み込み(ドラッグ&ドロップも可)
  • 「クリア」— エディタの内容を消去(Ctrl+Zで復元可能)
  • 「Markdownダウンロード」「HTMLダウンロード」— 現在の内容をファイルとして保存

自動保存

  • 入力内容とファイル名はブラウザのlocalStorageに自動保存され、タブを閉じても次回開いたときに復元されます

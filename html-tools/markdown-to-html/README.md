# Markdown → HTML 変換ツール

:sparkles: ブラウザだけで動く Markdown → HTML 変換ツールです。

Markdown を書くとその場でプレビューされ、スタイル込みの HTML ファイルとして保存できます。HTML ファイル 1 つだけで動きます。

こんなときに
- ブラウザだけで Markdown が書ける
- 手順書・議事録・メモを、そのまま人に渡せる HTML にしたい
- 「Markdown をまだ触ったことがない」人の入り口として

## 使い方

1. `markdown_to_html.html` を手元にダウンロード
2. ブラウザで開く（ダブルクリックでOK）
3. 左に Markdown を書く → 右にリアルタイムでプレビュー
4. ファイル名を入れて「ダウンロード」→ スタイル付きの HTML が保存されます

## ポイント

- インストール不要・アカウント不要・設定不要
- 入力内容がどこかに送信されることはありません。変換はすべてブラウザ内で完結します
- 保存した HTML は単体で開けます。受け取った人の側に特別な環境は要りません
- 見出し・箇条書き・表・コードブロック・引用に対応
- Markdown 標準にはない文字色も、`<span style="color:#e63946;">赤い文字</span>` のように書けば反映されます
- オフライン環境でも動作します。外部サーバーへの通信は一切発生しません

開いた直後に主要な記法をひと通り詰めたサンプル（`markdown_to_html_sample.html`）が入っているので、上書きしながら試すのが手っ取り早いです。

## 更新履歴（追加機能）

新しいものから順に。

- **左右ペイン幅の可変化**（2026-08-12）
  境界線をドラッグして入力欄／プレビューの幅を自由に変更可能に。ダブルクリックで50:50にリセット、境界線を選択した状態なら矢印キーでも微調整できる。比率はブラウザに記憶され、次回開いたときも復元される。
- **使い方ヘルプ**（2026-08-12）
  ヘッダーの `?` ボタンから、ツールバー・ショートカット・画像・ファイル操作・自動保存の説明をモーダルで確認できるように。背景クリックと Esc キーでも閉じられる。
- **クリアボタン**（2026-08-12）
  エディタの内容を一括消去するボタンを追加。誤操作防止の確認ダイアログを挟み、実行後も Ctrl+Z で復元可能。
- **Undo/Redo ショートカット**（2026-08-12）
  ツールバー操作や Tab インデントはブラウザ標準の Undo 履歴に乗らないため、独自の履歴スタックを実装。Ctrl(Cmd)+Z で元に戻す、Ctrl(Cmd)+Shift+Z でやり直す。
- **エディタ機能の大幅拡充**（2026-08-11）
  単一 HTML のまま使い勝手を高めるための一括アップデート。
  - Tab / Shift+Tab でリストのインデント挿入・解除（単一行・複数行選択どちらも対応）
  - Markdown のダウンロード・インポート（.md 読み込みでエディタとファイル名欄を更新）
  - 画像の貼り付け・ドラッグ＆ドロップを Base64 データ URI として本文に直接埋め込み（外部ファイル参照なし。幅1600pxを超える画像は自動で JPEG に縮小変換）
  - .md ファイルのドラッグ＆ドロップインポート
  - 自動保存（localStorage）とリロード時の復元
  - 離脱前の警告（未ダウンロードの変更がある場合のみ）
  - 簡易ツールバー（見出し・太字・斜体・取り消し線・引用・箇条書き・コード・リンク）
  - エディタ／プレビューの同期スクロール
  - 文字数・行数カウンター

§手順書エディタ
シート一覧

使い方

シート

  • 左のシート一覧で手順書を複数シートに分けて管理できます
  • 「＋ シートを追加」で新規作成、⠿ をドラッグして並び替え
  • タブ内の ↑↓ で移動、⧉ で複製、✕ で削除（最後の1枚は削除不可）
  • タブの名前欄はクリックして直接編集できます

手順

  • 「＋ 手順を追加」で新規作成
  • 手順を右クリックすると、上/下に追加・複製・削除ができます
  • ⠿ をドラッグすると並び替え、左のシートタブへドロップすると別シートへ移動できます

画像

  • 手順をクリックすると「貼り付け先」になり、その状態で Ctrl+V で画像を貼り付けられます
  • ドラッグ&ドロップでも画像を追加できます

検索・置換

  • Ctrl+F — 検索バーを開く（Escで閉じる）
  • Enter / Shift+Enter — 次/前の一致へ移動
  • 置換欄に入力して「全置換」（または置換欄で Enter）

キーボードショートカット

  • Ctrl+S — JSON保存
  • Ctrl+Z / Ctrl+Shift+Z（または Ctrl+Y） — 元に戻す/やり直す
  • Esc — 検索バー・メニューを閉じる

ファイル操作

  • 「JSON保存」「ファイル読込」— 作業データをファイルとして保存/読込（このツールが書き出したHTMLも読込可）
  • 「プレビュー（印刷確認）」— 書き出し結果を別画面で確認
  • 「HTMLエクスポート」— 単体で開けるHTMLファイルとして書き出し

自動保存

  • 編集内容はブラウザに自動保存され、閉じてしまっても次回開いたときに復元を確認できます

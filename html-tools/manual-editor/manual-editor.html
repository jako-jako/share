§手順書エディタ
1行に1つ 名前=値 と書くと、本文の {{名前}} が値に置き換わります（コードブロック内も含む）。# で始まる行はコメント。
シート一覧

使い方

シート

  • 左のシート一覧で手順書を複数シートに分けて管理できます
  • 「＋ シートを追加」で新規作成、⠿ をドラッグして並び替え
  • タブ内の ↑↓ で移動、⧉ で複製、✕ で削除（最後の1枚は削除不可）
  • タブの名前欄はクリックして直接編集できます

手順

  • 「＋ 手順を追加」で新規作成
  • 手順を右クリックすると、上/下に追加・複製・削除ができます
  • ⠿ をドラッグすると並び替え、左のシートタブへドロップすると別シートへ移動できます
  • 番号の下のチェックボックスで複数選択すると、画面下部のバーで別シートへの一括移動・一括削除ができます
  • 選択中の手順のどれかの番号をドラッグすると、選択した手順をまとめて（順番のまま）移動できます

画像

  • 手順をクリックすると「貼り付け先」になり、その状態で Ctrl+V で画像を貼り付けられます
  • ドラッグ&ドロップでも画像を追加できます。画像のある手順に入れると差し替え（キャプションは残り、注釈は引き継ぐか選択）
  • 画像をクリックすると注釈エディタ（選択・四角・丸・矢印・ペン・テキスト・番号・モザイク・切り抜き）が開きます
  • 画像の下のキャプションは改行でき、エクスポート後も改行されます（<br> と書いても改行になります）
  • 右クリックメニューから、クリップボードの画像で差し替え・画像の削除もできます

注釈エディタ

  • ← / → — 変更を自動保存して、同じシートの前後の画像へ移動
  • Ctrl+Z — 直前の書き込みを取り消し／Ctrl+Y — やり直し（全消去・切り抜きも戻せます）
  • 「選択」ツール — クリックで選択、ドラッグで移動、Delete で削除。選択中に色・線・文字サイズを押すとその図形に反映。テキストはダブルクリックで再編集
  • テキスト入力中 — Enter で改行、Ctrl+Enter または外側クリックで確定、Esc で取り消し
  • 「切り抜き」ツール — ドラッグで範囲を指定（やり直しは再ドラッグ）、画面下のバーか Enter で確定、Esc で解除。「保存」するまで元画像は変わりません
  • Esc — 未保存の変更を破棄して閉じる（図形を選択中は選択解除のみ）

検索・置換

  • Ctrl+F — 検索バーを開く（Escで閉じる）
  • Enter / Shift+Enter — 次/前の一致へ移動
  • 置換欄に入力して「全置換」（または置換欄で Enter）

作業内容欄のMarkdown

  • 基本: # 見出し / **太字** / *斜体* / ~~取消線~~ / ==マーカー== / `コード` / ```コードブロック```
  • リスト: - 項目（半角スペース2つで階層化）/ 1. 番号付き / - [ ] チェック項目
  • その他: > 引用 / --- 区切り線 / [文字](URL) リンク（URLは直書きでも自動リンク）/ | 表 |
  • 警告枠: > [!WARNING] 再起動前にバックアップ（NOTE / TIP / IMPORTANT / WARNING / CAUTION）
  • 記入欄: [[記入]] / [[記入:確認したPID]] — 印刷すると下線の空欄になり、ペンで書き込めます
  • キー表示: [[Ctrl+Alt+Del]]
  • 期待結果: ```expected で囲むと「期待結果」ラベル付きで表示（output / 期待結果 も可）
  • 変数: 上部の「{{ }} 変数」に HOST=web01 と書くと、本文の {{HOST}} が置き換わります（コードブロック内も）。\{{HOST}} と書くとそのまま表示
  • エクスポートしたHTMLでは、コードブロックの右上に「コピー」ボタンが付きます（印刷には出ません）

作業内容欄の入力補助

  • Tab / Shift+Tab — 字下げ／字下げ解除（複数行選択でまとめて）
  • リストの行で Enter — 次の行に - や番号を自動入力（空の項目で Enter するとリスト終了）
  • Ctrl+B — 太字、Ctrl+E — コード（もう一度押すと解除）

キーボードショートカット

  • Ctrl+S — JSON保存
  • Ctrl+Z / Ctrl+Shift+Z（または Ctrl+Y） — 元に戻す/やり直す
  • Esc — 検索バー・メニューを閉じる、手順の選択を解除

ファイル操作

  • 「JSON保存」「ファイル読込」— 作業データをファイルとして保存/読込（このツールが書き出したHTMLも読込可）
  • 「プレビュー（印刷確認）」— 書き出し結果を別画面で確認
  • 「HTMLエクスポート」— 単体で開けるHTMLファイルとして書き出し（再編集用に注釈前の原本も入ります）
  • 「配布用HTML」— 注釈前の原本・図形を含まないHTML。モザイクで隠した内容が残らないため、社外へ渡すときはこちら
  • 「手順書出」— 全手順を CSV（シートNo・シート名・手順No・作業内容・備考・画像キャプション）で保存。Excel でレビュー・編集できます
  • 「手順読込」— 編集した CSV を読み込み、シートNo・手順No が一致する手順の作業内容・備考・画像キャプションを上書きします（不要な列は削っておけばその項目は変わりません。Ctrl+Z で戻せます）

自動保存

  • 編集内容はブラウザに自動保存され、閉じてしまっても次回開いたときに復元を確認できます

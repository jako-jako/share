1.このツールについて

テスト実施時のエビデンス（画面キャプチャ＋説明）を作成するためのツールです。従来のExcelにスクリーンショットを貼り付ける運用を置き換えることを目的としています。

  • インストール不要：HTMLファイルをブラウザで開くだけで動きます。共有フォルダに置けばチーム全員がそのまま使えます。
  • すべてブラウザ内で完結：画像もテキストも外部に一切送信されません。ネットワーク接続も不要です。
  • 成果物は1ファイル：画像込みの単一HTMLとして保存でき、ダブルクリックで誰でも閲覧できます（Excel不要）。

2.基本の流れ（クイックスタート）

  1. ツール（HTMLファイル）をブラウザで開く
    上部ツールバーでプロジェクト名・実施者・日付を入力します。
  2. テストケースを追加する
    ＋ テストケースを追加 を押し、タイトル・手順・期待結果を記入します。
  3. キャプチャを貼り付ける
    ケース内の点線枠をクリックして貼り付け先に選択し、PrintScreen 等で撮ったキャプチャを Ctrl+V で貼ります。何枚でも連続で貼れます。
  4. 注釈をつける
    サムネイルをクリックして注釈エディタを開き、四角・矢印・モザイクなどを書き込みます。→ キーで自動保存しながら次の画像へ進めます。
  5. 保存する
    自分の控え・作業再開用には 作業用保存、提出・共有用には 配布用保存 を押します。

3.ツールバーの設定項目

項目内容
プロジェクトレポートのタイトルおよび保存ファイル名になります。
実施者 / 日付レポートのヘッダーに表示されます。日付は開いた日の日付が自動入力されます。
縮小貼り付け時に画像の長辺をこのサイズまで自動縮小します。既定は 長辺800px。詳しくは 9章 を参照。
形式貼り付け時の画像圧縮形式。既定は JPEG 標準（品質85%）。ファイルサイズを大きく左右します。
作業用HTMLを読み込む「作業用保存」したファイルを開き、編集を再開します（7章）。
印刷 / PDF化ブラウザの印刷機能で紙またはPDFに出力します。
作業用保存 / 配布用保存成果物の書き出し。2つの違いは 7章 を必ず確認してください。
補足
「縮小」「形式」の設定はこれから貼り付ける画像に適用されます。すでに貼り付け済みの画像には影響しません。

4.テストケースの操作

  • 追加：ページ下部の ＋ テストケースを追加。追加したケースは自動的に「貼り付け先」になります。
  • タイトル編集：ケース見出しのタイトル部分を直接クリックして書き換えます。
  • 結果の記録：右側のプルダウンで 保留 / OK / NG を選びます。レポートのサマリ表に色付きで反映されます。
  • 折りたたみ：見出し左端の ▼ / ▶ でケースの中身を畳めます。ケースが多いときのスクロール量を減らせます。
  • 削除：「ケース削除」。中の画像ごと消えるため確認ダイアログが出ます。
  • 入力欄：手順 / 期待結果 / 総評・備考 の3欄。すべてレポートに出力されます（空欄は出力されません）。

5.画像の追加

各ケースの末尾にある点線枠が画像の追加ゾーンです。追加方法は3通りあります。

方法手順
貼り付け（推奨）点線枠をクリックして貼り付け先に選択（青枠でハイライトされます）→ Ctrl+V。一度選択すれば、画面のどこにいても連続で貼り付けられます。キャプチャ → 貼り付け → キャプチャ → 貼り付け…のループが最速です。
ドラッグ&ドロップ画像ファイルを点線枠へドロップします。複数ファイル同時も可能です。
ファイル選択点線枠内の「ファイル選択」ボタンから選びます。複数選択可能です。

貼り付けた画像は次の操作ができます。

  • 番号：左上のバッジが表示順の番号です。レポートの図番号（図2-3 など）に対応します。
  • 並べ替え：カード下部の ◀ ▶ で前後に移動します。手順の順序に合わせて整えられます。
  • コメント:カード下の入力欄に、その画像が何を示すかのメモを書けます。レポートでは図キャプションとして表示されます。
  • 削除：カード下部の「削除」。
補足
貼り付け先を選択していない場合、Ctrl+V の画像は一番下のケースに入ります。また、テキスト入力欄にカーソルがある間は画像貼り付けは動作しません（文章のコピペを妨げないためです）。

6.注釈のつけかた

サムネイルをクリックすると注釈エディタが開きます。元画像は保持されたまま注釈が上に乗る方式なので、後から開いて修正・削除できます。

ツール

ツール操作と用途
四角ドラッグで半透明のハイライト枠を描きます。注目箇所の強調に。
矢印始点から終点へドラッグ。指し示しに。
ペンフリーハンドの線。囲み込みなど自由な書き込みに。
テキスト置きたい位置をクリック → 入力ダイアログに文字を入れます。縁取り付きで画像の上でも読めます。
モザイクドラッグした範囲をピクセル化します。個人情報・社外秘のマスキングに。マスキングした場合の配布方法は必ず7章を参照してください。

色は赤・黄・青・緑の4色。「元に戻す」で1操作ずつ取り消し、「全消去」でその画像の注釈をすべて消せます。

画像間の移動（自動保存）

  • → / ← キー（または「次へ ›」「‹ 前へ」ボタン）で、現在の画像の注釈を自動保存してから同じケース内の次／前の画像に移動します。エディタを閉じずに20枚へ連続で注釈できます。
  • ツールバー中央の「3 / 20」が現在位置です。ケースの端に来ると移動ボタンはグレーアウトします（ケースはまたぎません）。
  • 最後は 保存して閉じる か Esc で閉じます。
「キャンセル」の意味に注意
矢印キーで移動するたびに注釈は確定保存されます。「キャンセル」(Esc) で破棄されるのはいま表示中の画像の未保存分だけです。移動で通過した画像の注釈は取り消されません（個別に開いて「全消去」してください）。

7.保存と読み込み（作業用と配布用）

保存ボタンは2種類あり、用途がはっきり分かれています。

作業用保存配布用保存
用途自分の控え・作業の中断/再開提出・共有・レビュー依頼
再編集可（「作業用HTMLを読み込む」で再開）不可（閲覧専用）
内容物表示用画像＋注釈前の元画像＋図形データ表示用画像のみ
サイズ大きい（約2倍）小さい
ファイル名プロジェクト名.htmlプロジェクト名_配布用.html
重要：モザイクをかけた画像がある場合
作業用ファイルにはモザイクをかける前の元画像がそのまま含まれており、HTMLのソースを見れば取り出せます。マスキングした内容を守る必要がある相手には、必ず「配布用保存」のファイルを渡してください。作業用ファイルは自分の手元、またはチーム内の安全な場所に限定してください。

作業の再開

  1. ツールバーの 作業用HTMLを読み込む を押す
  2. 「作業用保存」したHTMLファイルを選ぶ
  3. ケース・画像・注釈がすべて復元され、続きから編集できます

配布用ファイルは読み込めません（選ぶとその旨のメッセージが表示されます）。

8.レポートの見かた（レビュアー向け）

保存されたHTMLをダブルクリックで開くだけです。特別なソフトは不要です。

  • 冒頭のサマリ表で全ケースの結果（OK / NG / 保留）と画像枚数を一覧できます。ケース名をクリックすると該当箇所へジャンプします。
  • 画像をクリックすると拡大表示になります。拡大中は：
    • → / ← キー（または左右のボタン）で前後の画像へ移動。ケースをまたいで全画像を通しで確認できます。
    • 下部に図番号とコメント、右上に「12 / 47」の位置カウンターが表示されます。
    • Esc または背景クリックで閉じます。
  • 最初の画像をクリックして → を押し続けるだけで、全エビデンスを順に確認できます。

9.縮小・形式設定の考えかた

ファイルサイズは「縮小（画素数）」と「形式（圧縮）」の掛け算で決まります。画素数は長辺の2乗で効くため、縮小設定の影響が特に大きくなります。

設定目安
長辺800px（既定）標準。正方形に近いキャプチャでも文言が読みやすく、サイズも小さい。
長辺500px最小。従来のExcel運用で500px相当だった場合に。細かい文字は判読しづらくなるため、下の「採用前チェック」を推奨。
長辺1200〜1600px細部の文字まで確実に読ませたい場合。サイズは大きくなります。
JPEG 標準（既定）画面キャプチャでPNGの1/4〜1/6程度。エビデンス用途では通常これで十分です。
PNG無劣化。文字のにじみを一切許容できない場合のみ。サイズは大幅に増えます。
採用前チェック（小さい設定にする前に）
本番でよく撮る画面を1枚、その設定で貼ってみて、エビデンスとして読めてほしい部分（結果の値・メッセージ文言）が判読できるかを確認してください。読めなければ1段階大きい設定にします。一度小さく取り込んだ画像は後から高精細に戻せません。

また、ウィンドウ全体を毎回撮るのではなく、Win+Shift+S の範囲選択で変化のある領域だけを撮ると、小さい設定でも文字が読みやすく、レビュアーも差分を追いやすくなります。

10.注意事項

  • 作業内容はブラウザを閉じると消えます。タブを閉じる・リロードする際には警告が出ますが、長時間の作業ではこまめに「作業用保存」をしてください。自動保存機能はありません。
  • 1ケースあたりの画像枚数に制限はありませんが、枚数と設定によってはファイルが数十MBになることがあります。保存時に画面下へ表示されるサイズを目安にしてください。
  • 保存済みファイルの内容を修正したい場合は、「作業用HTMLを読み込む」→ 修正 → 再度保存、の流れになります。配布済みの配布用ファイル自体は編集できません。
  • ツール・レポートともに一般的なブラウザ（Edge / Chrome）での利用を想定しています。

使い方

テストケース

  • 「＋ テストケースを追加」で新規カードを作成
  • 結果は各カードのプルダウンで 保留/OK/NG を選択（色分け表示）
  • ▲▼で折りたたみ、「全折りたたみ」で一括切り替え
  • ⧉複製で画像・注釈を含めて複製、↑↓で並び替え

画像

  • カードをクリックすると「貼り付け先」になり、その状態で Ctrl+V で画像を貼り付けられます
  • ドラッグ&ドロップ、または「ファイル選択」からも追加できます
  • 画像をクリックすると注釈エディタ（選択・四角・丸・矢印・ペン・テキスト・番号・モザイク・切り抜き）が開きます
  • 「差替」（または右クリック）で、コメント・表示幅を残したまま画像だけ差し替え（注釈は引き継ぐか選択）
  • ◀▶で並び替え、⧉で複製、幅ボタン（100/50/33/25%）またはドラッグで表示幅を変更
  • チェックボックスで複数選択すると、画面下部のバーで幅の一括変更・別ケースへの一括移動・一括削除ができます
  • 選択中の画像のどれかをドラッグすると、選択した画像をまとめて（表示順のまま）移動できます

注釈エディタ

  • ← / → — 変更を自動保存して前後の画像へ移動
  • Ctrl+Z — 直前の書き込みを取り消し／Ctrl+Y — やり直し
  • 「選択」ツール — クリックで選択、ドラッグで移動、Delete で削除。選択中に色・線・文字サイズを押すとその図形に反映。テキストはダブルクリックで再編集
  • テキスト入力中 — Enter で改行、Ctrl+Enter または外側クリックで確定、Esc で取り消し
  • 「切り抜き」ツール — ドラッグで範囲を指定（やり直しは再ドラッグ）、画面下のバーか Enter で確定、Esc で解除。確定後も Ctrl+Z で戻せます
  • Esc — 未保存の変更を破棄して閉じる（図形を選択中は選択解除のみ）

検索・置換

  • Ctrl+F（または「検索」ボタン）— 検索バーを開く
  • Enter / Shift+Enter — 次/前の一致へ移動
  • 置換欄に入力して「全置換」（または置換欄で Enter）、Escで閉じる

キーボードショートカット

  • Ctrl+S — 作業用保存
  • Ctrl+Z / Ctrl+Shift+Z（または Ctrl+Y） — 元に戻す/やり直す

保存・印刷

  • 「作業用保存」— 編集を続けられる状態のままHTMLとして保存し、後で「作業用HTMLを読み込む」で読み直せます
  • 「配布用保存」— 編集用のボタン類を含まない、閲覧・印刷用のHTMLとして保存します
  • 「印刷 / PDF化」— 編集用のUIを除いた状態で印刷プレビューを開きます
  • 「コメント書出」— 全画像のコメントを CSV（ケースNo・ケース名・画像No・図番号・コメント）で保存。Excel で編集できます
  • 「コメント読込」— 編集した CSV を読み込み、ケースNo・画像No が一致する画像のコメントを上書きします（Ctrl+Z で戻せます）
  • コメントの改行は報告書の図キャプションでも改行されます（<br> と書いても改行になります）

自動保存

  • 編集内容はブラウザに自動保存され、閉じてしまっても次回開いたときに復元を確認できます
